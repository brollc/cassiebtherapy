# Publii Themes — Cassie B Therapy

Two installable Publii themes live here. Install the ZIP in Publii via the
three-dot menu → **Themes** → **Install theme**.

## `cassieb` — "Cassie B Therapy" (current)

A pixel-faithful Publii port of the live static site (green botanical design,
Fraunces + Nunito Sans, headshot + sunrise, masonry beliefs, all current
content). All text lives in **Theme settings** tabs; the three depth pages
(About, The Work, Bookshelf) render from dedicated page templates — create
one page per section in Publii, pick its template in the page editor, and
use the slugs `about`, `the-work`, `bookshelf` so the homepage dive links
resolve. Full instructions: `cassieb/README.md`.

## `cassieb-serene` — "Cassie B Therapy Serene" (alternate design)

The calm Wix-inspired blue/cream design. Content is synced with the current
site; depth-page content lives in theme settings for pasting into Publii
pages. Full instructions: `cassieb-serene/README.md`.
